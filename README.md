# claude-code-plugins

Claude Code plugin marketplace by [Senara Solutions](https://github.com/senara-solutions).

## Install

```bash
claude marketplace add https://github.com/senara-solutions/claude-code-plugins
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [claude-asked](plugins/claude-asked/) | Forwards hook events to a command or webhook when Claude needs your input |
